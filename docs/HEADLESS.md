# Headless workflow status

WGLink currently sends a Fusion model to Waveguide Generator (WG) for interactive setup and solving. The WG Metal pipeline commands previously documented here have moved out of this repository with the frozen legacy fallback; commands under this repository's former `scripts/` path no longer exist.

For the maintained path, install WG and WGLink, press **Send** in Fusion, then configure and solve the imported model in WG. A supported WGLink headless Solve command is planned, but has not been delivered yet. Until then, use WG's supported interface for the job so its setup, ownership and run history remain consistent.
