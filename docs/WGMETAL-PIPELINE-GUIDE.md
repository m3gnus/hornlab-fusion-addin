# Retired WG Metal Pipeline guide

The WG Metal pipeline add-in and its scripts were removed from this repository after a standalone legacy fallback was verified. This guide is retired because its installation and command paths would now be incorrect.

For the maintained workflow, see the [WGLink user guide](WGLINK-GUIDE.md). The frozen standalone fallback keeps its own README and headless instructions in its own installation. It is independent of WGLink and is not updated by this repository.
